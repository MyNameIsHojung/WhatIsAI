# Gemini용 글귀 다듬기 프롬프트

아래 내용을 그대로 Gemini CLI에 넘깁니다. 대상 파일은 `content/copy.json` 하나입니다.

---

`content/copy.json`은 사내 세미나용 인터랙티브 웹페이지의 모든 글귀를 담은 파일입니다. 이 파일의 한국어 문장을 더 재미있고 쉽게 다듬어 주세요.

## 독자
- 개발자이지만 AI는 코드 자동완성 정도로만 써본 사람들입니다.
- 그래도 비개발자가 읽어도 이해될 만큼 쉽게 써야 합니다.
- 세미나에서 발표자와 함께 화면을 보며 직접 눌러보는 자리입니다.

## 말투
- 친한 선배가 커피 마시면서 설명해 주는 느낌. 존댓말(해요체 위주).
- 전문용어는 반드시 비유를 먼저, 용어는 그다음에. 처음 나오는 영어 약어는 한 번 풀어 씁니다.
- 한 문장은 짧게. `lead`는 3문장 이내, `takeaway`는 2~3문장.
- 가벼운 농담은 좋지만 섹션당 하나까지. 과장된 감탄사, 유행어, 이모지 남발은 피합니다.
- 교과서나 논문 같은 표현("~라고 할 수 있다", "본 절에서는")은 쓰지 않습니다.

## 반드시 지킬 것
1. JSON 구조, 키 이름, `id`, `widget`, `need`, `skill`, `type`, `image` 값은 절대 바꾸지 않습니다.
2. 숫자(`p`, `logit`, `min`, `part`)는 바꾸지 않습니다. `rounds[].options`의 `p` 합은 100이어야 합니다.
3. `{top}`, `{tool}`, `{chars}`, `{tokens}`, `{now}`, `{all}`, `{list}` 같은 중괄호 자리표시는 그대로 둡니다.
4. 기술적 사실을 바꾸지 않습니다. 특히 다음 정의는 의미가 유지되어야 합니다.
   - LLM: 다음에 올 토큰을 확률로 예측한다.
   - 도구 사용: 모델은 요청만 하고, 실행은 바깥 프로그램이 한다.
   - 에이전트: 생각 → 행동 → 관찰을 스스로 반복한다.
   - MCP: AI와 외부 서비스를 연결하는 공통 규격이다.
   - 스킬: 필요할 때만 불러와 읽는 지침 묶음이다.
   - 하네스: 모델을 감싸 루프, 도구, 컨텍스트, 권한을 관리하는 프로그램이다.
5. `questions[1]`의 계산 예시(48,273 × 9,176 = 442,953,048)는 숫자를 건드리지 않습니다.
6. 결과는 유효한 JSON 파일 전체로, 같은 경로에 덮어씁니다. 설명이나 주석은 넣지 않습니다.

## 더 좋아지면 좋은 곳
- `predict`의 문제 3개: 개발자가 피식할 만한 상황으로 바꿔도 좋습니다. 선택지 4개 중 마지막 하나는 엉뚱한 답으로 유지합니다.
- 각 섹션 `title`: 한눈에 들어오는 한 줄. 20자 안팎.
- `questions[].alone`: 모델이 그럴듯하게 틀리는 느낌이 살아야 합니다.
