# Codex용 이미지 생성 프롬프트

아래 내용을 그대로 Codex에 넘깁니다. 결과물은 `assets/img/` 폴더에 지정한 파일 이름으로 저장합니다.
이미지가 없는 동안에는 페이지가 이모지 카드로 대신 보여주므로, 일부만 먼저 만들어도 됩니다.

---

사내 세미나용 웹페이지에 들어갈 일러스트 11장을 만들어 `assets/img/`에 저장해 주세요.

## 공통 스타일 (모든 이미지에 동일하게 적용)
- 플랫 벡터 일러스트, 굵고 균일한 짙은 남색(#1F1B2E) 외곽선, 그림자는 단색으로 단순하게.
- 색은 다음 다섯 가지와 흰색만 사용: 노랑 #FFC93C, 다홍 #FF5B3A, 파랑 #3B5BFF, 민트 #19C39C, 크림 #FFF8EC.
- 배경은 노랑(#FFC93C) 단색. 그라데이션, 사진풍, 3D 질감은 쓰지 않습니다.
- 정사각형 1024×1024 PNG. 가장자리에 여백을 넉넉히 두고 주제를 가운데에 크게.
- 이미지 안에 글자, 숫자, 로고는 넣지 않습니다.
- 주인공은 항상 같은 마스코트: 둥근 네모 머리에 안테나 하나, 큰 점 눈 두 개, 짧은 팔다리를 가진 작은 흰색 로봇 "토리". 표정이 풍부하고 귀엽습니다. 모든 장에서 생김새가 같아야 합니다.

| `tools.png` | 토리가 공구 벨트를 차고 한 손에 돋보기, 다른 손에 계산기를 든 채 자신만만하다. |
| `loop.png` | 토리가 원형 트랙 위를 달린다. 트랙에는 화살표가 빙 둘러 있고 결승 깃발이 보인다. |
| `mcp.png` | 토리가 커다란 플러그를 콘센트에 꽂는다. 콘센트 뒤로 여러 색의 케이블이 뻗어 있다. |

| `harness.png` | 토리가 엔진만 놓인 차대에 바퀴와 핸들을 조립하고 있다. 반쯤 완성된 귀여운 자동차. |
| `outro.png` | 토리가 큰 지도를 펼쳐 들고 깃발 꽂힌 목적지를 가리키며 웃는다. |
| `context.png` | 토리가 작은 책상 앞에 앉아 있다. 책상 위에 종이와 책이 넘치도록 쌓여 몇 장이 바닥으로 떨어진다. |
| `hallucination.png` | 탐정 모자를 쓴 토리가 돋보기로 말풍선 두 개를 살핀다. 하나에는 체크 표시, 하나에는 엑스 표시. |
| `rag.png` | 토리가 서류 서랍장에서 서류 한 장을 뽑아 들고 읽는다. 열린 서랍에서 종이들이 살짝 보인다. |
| `team.png` | 큰 토리 하나가 앞에 서서 지시하고, 똑같이 생긴 작은 토리 셋이 각자 서류를 들고 바쁘게 움직인다. |
| `usage.png` | 토리가 네 칸짜리 계단을 한 칸씩 오른다. 맨 위 칸에 깃발이 꽂혀 있다. |

| `safety.png` | 토리가 커다란 빨간 버튼 앞에서 한 손을 들고 누르기 전에 물어보는 표정을 짓는다. 옆에 정지 표지판 모양. |
| `generate.png` | 토리의 머리 위에 점과 선으로 이어진 작은 그물망(신경망)이 떠 있고, 그 끝에서 말풍선 조각이 하나씩 나온다. |

| `trends.png` | 토리가 카드 한 장을 뒤집고 있다. 카드 앞면과 뒷면의 색이 다르고 주변에 반짝임이 튄다. |
| `lineup.png` | 서로 다른 모양의 건물 네 채가 나란히 서 있고, 토리가 그 앞에서 안내하듯 손으로 가리킨다. |
| `tiers.png` | 토리가 양팔저울 앞에 서 있다. 저울 한쪽에는 큰 상자, 다른 쪽에는 작은 상자 여러 개가 놓여 있다. |
| `credits.png` | 토리가 색이 다른 로봇 친구 둘, 사람 한 명과 함께 손을 모아 하이파이브를 한다. |

## 확인할 것
- 11장을 나란히 놓았을 때 한 시리즈로 보여야 합니다. 색, 선 굵기, 토리의 생김새가 어긋나면 다시 만듭니다.
- 작게(160px) 줄여도 무슨 장면인지 알아볼 수 있어야 합니다.
