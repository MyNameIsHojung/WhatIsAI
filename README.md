# AI, 알고 보면 별거 아니에요

직접 눌러보면서 배우는 AI 세미나 자료입니다. LLM이 어떻게 글을 만드는지부터 도구, MCP, 스킬, 하네스까지를 설명 대신 체험으로 풀었습니다.

**바로 보기: https://mynameishojung.github.io/WhatIsAI/**

AI를 코드 자동완성 정도로만 써본 개발자를 대상으로 하되, 비개발자가 봐도 이해할 수 있게 만들었습니다. 발표자가 화면을 띄워 진행하고, 참석자는 각자 같은 주소로 들어와 함께 눌러보는 방식을 염두에 두었습니다.

## 구성

| 부 | 화면 |
|---|---|
| 1부 · LLM의 원리와 한계 | 원리, 생성 과정, 온도, 토큰, 컨텍스트 창, 한계, 환각 퀴즈 |
| 2부 · 한계를 넘는 확장 도구 | 도구, 검색해서 답하기, 에이전트, MCP, 스킬, 하네스, 서브에이전트 |
| 3부 · 실전 활용법 | 쓰임새 4단계, 잘 시키는 법, 권한 |
| 4부 · 요즘 LLM 현황 | 흐름, 달라진 점, 누가 만드나, 고르는 법 |
| 마무리 | 정리, 만든 과정 |

화면마다 체험이 하나씩 있고, 왼쪽의 "한 줄 요약" 버튼을 누르면 정리 문장과 토론 질문이 나옵니다. 2부 화면에는 실제 제품 예시와 공식 링크를 보여주는 "실제로는 이렇게 쓰여요" 버튼도 있습니다.

## 조작법

- `←` `→` 키: 이전, 다음 화면
- `F` 키 또는 왼쪽 위 "전체화면" 버튼: 전체화면 켜고 끄기
- 왼쪽 위 "목차" 버튼: 목차로 이동
- 오른쪽 점: 원하는 화면으로 바로 이동

넓은 화면에서는 화면 하나가 슬라이드 한 장처럼 창 크기에 맞춰 표시됩니다. 휴대폰처럼 좁은 화면에서는 세로로 스크롤합니다.

## 로컬에서 실행하기

빌드 과정이 없는 정적 사이트입니다. 글귀를 `fetch`로 불러오기 때문에 파일을 직접 여는 대신 간단한 서버로 띄워야 합니다.

```bash
python3 -m http.server 8765
```

그다음 브라우저에서 `http://localhost:8765`를 엽니다.

## 폴더 구조

```text
index.html            페이지 뼈대
css/style.css         스타일
js/main.js            화면 조립, 화면 맞춤, 이동
js/widgets.js         체험 위젯
content/copy.json     모든 글귀와 체험 데이터
assets/img/           그림
prompts/              글귀와 그림을 만들 때 쓴 프롬프트
```

## 내용 고치기

글귀는 전부 `content/copy.json`에 있습니다. 코드를 건드리지 않고 이 파일만 고치면 됩니다.

- `meta`: 시작 화면, 부 이름, 마지막 인사 화면
- `sections[]`: 화면 하나가 항목 하나입니다. `kicker`(목차에 나오는 짧은 이름), `title`, `lead`, `takeaway`, `discuss`, `examples`, 그리고 체험에 쓰이는 `data`가 들어 있습니다.
- 화면 순서는 `sections` 배열의 순서를 따르고, `part` 값으로 어느 부에 속하는지 정합니다.

4부의 모델 이름과 연표는 2026년 11월 기준입니다. 모델 이름과 버전은 자주 바뀌므로 발표 전에 확인하는 것을 권합니다.

## 만든 방법

이 페이지는 사람이 방향을 정하고 AI 여럿이 역할을 나눠 만들었습니다.

| 누가 | 한 일 |
|---|---|
| 사람 | 방향 정하기와 최종 판단 |
| Claude Code | 기획, 웹 구현, 조립과 검증 |
| Gemini CLI | 글귀 다듬기 |
| Codex | 그림 그리기 |

사용한 프롬프트는 `prompts/` 폴더에 있습니다.
